## Featured Projects

### SizzlerSnap - Stop Searching. Start Working.

**JavaScript | Chrome Extensions API | HTML/CSS**

Finding a product shouldn't require digging through spreadsheets, opening endless tabs, or repeatedly copying and pasting information.

So I built SizzlerSnap.

A privacy-first Chrome extension designed to make product model-number searches fast, simple, and accessible directly from your browser.

**What it delivers:**
- Instant model-number lookup and one-click copying.
- On-page highlighting, ranked search, and keyboard shortcuts.
- Importable product catalogs with offline access.
- Local browser storage without uploading catalog data to a server.

**Less searching. More getting things done.**

### FieldVision X - Predictions Are Easy. Accountability Is Hard.

**Python | Statistical Modeling | Data Pipelines **

Anybody can make a prediction.

The interesting question is whether that prediction survives contact with reality.

FieldVision X is an NFL forecasting and research platform built around historical data, statistical modeling, probability estimation, and reproducible evaluation.

**What it delivers:**
- Pregame win probability estimates.
- Historical backtesting and model evaluation.
- Automated data pipelines and season simulations.
- Forecast locking to distinguish predictions from actual outcomes.
- Interactive analysis and performance tracking.

**The goal isn't to be right every time. It's to know exactly how often you're wrong.**

## My Philosophy

I believe good software should accomplish three things:

1. **Solve a real problem.** If it doesn't improve something, why build it?
2. **Eliminate unnecessary complexity.** Simplicity is an advantage, not a limitation.
3. **Deliver results.** An idea means very little until it becomes something people can actually use.

I'm constantly exploring new technologies, improving existing projects, and finding problems worth solving.

### The Bottom Line

AI has made building software easier than ever.

**But just because you can build something doesn't mean it's worth building.**

I'm not interested in creating software simply because the technology makes it possible.

**I'm interested in building software because there's a better way to do something.**

And when I find that better way..

**I build it.**
